# QQ 执行权限与确认

身份只由桥接保存的真实消息决定。配置的主人 QQ 必须对应当前 `origin: message`，通知、提醒、自主任务或缺少来源的上下文均不继承主人身份；工具参数中的角色与确认声明无效。

| 操作 | 普通成员 | 主人真实消息 | 自主任务 |
| --- | --- | --- | --- |
| 当前会话回复、媒体、记录与普通记忆 | 按功能开关、范围及额度 | 同左 | 仅任务允许的能力与原会话 |
| 联系人枚举、跨会话发送或读取 | 拒绝 | 已有联系人且在允许范围内 | 拒绝 |
| 群成员与群内名片查询 | 当前群 | 允许范围内已加入群 | 按任务能力限制 |
| 名片点赞 | 当前发言者 | 允许范围内好友 | 按任务能力限制 |
| 提醒查看和取消 | 自己在当前会话创建的提醒 | 当前会话全部提醒 | 不自动获得任务管理权限 |
| 删除锁定记忆 | 拒绝 | 允许 | 拒绝 |
| 账号资料、头像、群名片与申请处理 | 拒绝 | 开关、确认及目标再次校验 | 拒绝 |
| 空间浏览、评论与发布 | 拒绝 | 独立开关与范围 | 仅对应空间任务及其限定目标 |

`src/security/tool-policy.ts` 为全部 QQ 工具登记访问类型；工具目录新增条目时，缺少策略即拒绝执行，契约测试要求目录与策略一致。MCP 展示过滤仅减少可见工具，执行处始终重新核验。普通成员的能力查询不返回联系名单；申请只向主人开放，返回事件时移除执行端使用的原始 flag 和令牌。

确认展示真实工具、会话、发起者及参数，超过展示长度的内容附完整摘要。确认绑定完整参数、发起身份、当前配置及有效期，不接受模型自报确认。等待或排队期间设置、目标或正文变化后，旧确认失效；实际执行前再次检查。主人私聊回复的编号只用于本次请求，取消或超时即移除。空间发布和评论分别保留正文及目标确认，未获确认不执行。

## 受限模型工具

运行覆盖配置加载全局工具守卫，只允许 `mcp__qq__` 中实际登记的 QQ 工具，以及 DSH 的 `web_search`、`web_fetch`。默认不挂载文件、Shell、子代理、工作流等工具；即使某个 Profile 再次注册这些工具，守卫也在执行入口拒绝它们，包含嵌套分派。旧 `allowExec` 值保留用于配置兼容，界面不能用它开放命令权限。

桥接使用每次启动的新随机值确认守卫确已加载，缺失或组件接口不兼容时拒绝开放模型业务。新安装组件在激活前验证覆盖配置的 ACP 初始化及实际工具注册器。网页读取拒绝本机、局域网、带账号或非 HTTP(S) 地址，固定组件的 HTTP 后端继续执行地址解析与连接绑定。

已验证 DSH 0.2.1-rc.2 / Node 24.22.1：实际注册器阻止文件、命令及其他 MCP，允许受控 QQ 工具；前置监听器返回允许也不能覆盖守卫的拒绝；HTTP 后端拒绝回环、私网及元数据地址。以下命令使用隔离 DSH Home，不调用模型或 QQ：

```powershell
node scripts/components/verify-tool-policy.mjs <Node路径> <DSH组件目录> <程序目录>
```

此处是受管组件的模型工具执行边界，不是 Windows 进程沙箱。管理员手工安装的第三方 Profile 插件属于同一用户权限下的本地代码；不要把任意第三方插件或程序当作受隔离的模型输入。Windows 凭据保护与完整进程树回收另行实施。
