# QQ 执行权限与确认

身份只由桥接保存的真实消息决定。配置的主人 QQ 必须对应当前 `origin: message`，通知、提醒、自主任务或缺少来源的上下文均不继承主人身份；工具参数中的角色与确认声明无效。

| 操作 | 普通成员 | 主人真实消息 | 自主任务 |
| --- | --- | --- | --- |
| 当前会话回复、媒体、记录与普通记忆 | 按功能开关、范围及额度 | 同左 | 仅任务允许的能力与原会话 |
| 联系人枚举、跨会话发送或读取 | 拒绝 | 已有联系人且在允许范围内 | 拒绝 |
| 群成员与群内名片查询 | 当前群 | 允许范围内已加入群 | 按任务能力限制 |
| 名片点赞 | 当前发言者 | 允许范围内好友 | 按任务能力限制 |
| 提醒查看和取消 | 自己在当前会话创建的提醒 | 当前会话全部提醒 | 不自动获得任务管理权限 |
| 删除锁定记忆 | 拒绝 | 允许 | 拒绝 |
| 账号资料、头像、群名片与申请处理 | 拒绝 | 开关、确认及目标再次校验 | 拒绝 |
| 空间浏览、评论与发布 | 拒绝 | 独立开关与范围 | 仅对应空间任务及其限定目标 |

`src/security/tool-policy.ts` 为全部 QQ 工具登记访问类型；工具目录新增条目时，缺少策略即拒绝执行，契约测试要求目录与策略一致。MCP 展示过滤仅减少可见工具，执行处始终重新核验。普通成员的能力查询不返回联系名单；申请只向主人开放，返回事件时移除执行端使用的原始 flag 和令牌。

确认展示真实工具、会话、发起者及参数，超过展示长度的内容附完整摘要。确认绑定完整参数、发起身份、当前配置及有效期，不接受模型自报确认。等待或排队期间设置、目标或正文变化后，旧确认失效；实际执行前再次检查。主人私聊回复的编号只用于本次请求，取消或超时即移除。空间发布和评论分别保留正文及目标确认，未获确认不执行。

## 受限模型工具

运行覆盖配置加载全局工具守卫，只允许 `mcp__qq__` 中实际登记的 QQ 工具，以及 DSH 的 `web_search`、`web_fetch`。默认不挂载文件、Shell、子代理、工作流等工具；即使某个 Profile 再次注册这些工具，守卫也在执行入口拒绝它们，包含嵌套分派。旧 `allowExec` 值保留用于配置兼容，界面不能用它开放命令权限。

桥接使用每次启动的新随机值确认守卫确已加载，缺失或组件接口不兼容时拒绝开放模型业务。新安装组件在激活前验证覆盖配置的 ACP 初始化及实际工具注册器。网页读取拒绝本机、局域网、带账号或非 HTTP(S) 地址，固定组件的 HTTP 后端继续执行地址解析与连接绑定。

已验证 DSH 0.2.1-rc.2 / Node 24.22.1：实际注册器阻止文件、命令及其他 MCP，允许受控 QQ 工具；前置监听器返回允许也不能覆盖守卫的拒绝；HTTP 后端拒绝回环、私网及元数据地址。以下命令使用隔离 DSH Home，不调用模型或 QQ：

```powershell
node scripts/components/verify-tool-policy.mjs <Node路径> <DSH组件目录> <程序目录>
```

此处是受管组件的模型工具执行边界，不是 Windows 进程沙箱。管理员手工安装的第三方 Profile 插件属于同一用户权限下的本地代码；不要把任意第三方插件或程序当作受隔离的模型输入。

## 受管进程与恢复

桌面共用管理服务与命令行入口在加载桥接、QQ 及配置业务前建立进程保护。Windows 使用独立辅助程序，为每个直接业务子进程建立带 `KILL_ON_JOB_CLOSE` 的 Job；辅助程序确认父子关系后才允许业务入口加载。停止单个组件、组件根进程退出、辅助程序异常退出或管理宿主被强制结束时，均回收对应的完整进程树；不按进程名结束其他实例或外部 OneBot。发行包内置辅助程序，不依赖用户安装编译器。机制依据 [Windows Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)。

管理服务区分停止、连接、等待登录、就绪、恢复和待处理状态。桥接与 QQ 分别监督，桥接退出不结束正常 QQ 登录；意外退出按 1/2/4/8/16 秒并附随机抖动恢复，十分钟最多自动恢复五次，连续就绪一分钟后重置计数。配置、凭据、磁盘满、数据损坏与实例冲突不自动重试。停止、退出和手动重启立即撤销原有恢复计时；原生窗口可在等待期间取消恢复，并提供诊断及手动重试入口。

进程保护用于生命周期回收，不限制进程访问同一 Windows 用户的文件或网络。测试覆盖真实 Windows 子孙进程、无关进程存活、宿主与辅助程序强制退出、发行版辅助程序，以及桥接单独恢复、待登录、损坏数据和取消恢复。该结果不能替代系统断电、干净机器安装或连续运行验收。

## Windows 凭据

Windows 发行版的已安装及便携布局，通过桌面或共用配置服务保存 OneBot 令牌、项目模型 Key、独立媒体和后台分析 Key 时，使用当前 Windows 用户作用域的 DPAPI 加密；`.env` 只保存随机凭据引用，密文位于数据目录的 `.credentials/`。正常入口启动时解析引用，再把所需值传入对应进程；不要把引用直接当作第三方服务的密钥。DSH 不继承 OneBot、媒体和后台分析凭据，NapCat 不继承模型、媒体和后台分析 Key。

首次替换旧明文前，先生成加密的原环境恢复材料，并验证当前用户能够解密新凭据；保存失败保留原配置。没有修改的密钥复用原引用。源码运行保留旧 `.env` 兼容方式；已经保护的配置从源码打开后保存也不会降级为明文。DSH 自身的账号/Profile 凭据及 NapCat 上游配置仍按各自的格式管理，不属于本凭据库。

更换 Windows 用户、移动到另一台机器或密文损坏而不能解密时，实际启动拒绝使用该凭据，表单仍可打开并逐项提示重新输入。密钥不出现在加密辅助进程的命令行、错误或普通日志中；辅助进程只继承 Windows 必需环境，恢复材料同样加密。`.credentials/` 属于私有运行数据，不提交、不随程序包分发，也不能放入可分享诊断包。
