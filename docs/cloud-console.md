# 私有浏览器控制台

目前已实现主人认领与登录、带修订号的连接配置编辑、独立密钥更新、启停任务、Windows 组件准备与取消、运行状态及有界 SSE 事件。界面支持桌面和手机，仅监听 `127.0.0.1`；可通过 SSH 隧道访问。账号管理、完整连接测试、备份恢复、公网 HTTPS 与二次验证尚未接入。

已在 Windows / Node 24.22.1 验证后台，在本机 Edge 验证实际页面。首个目标平台仍为用户确认的 Linux x64，但 Linux 服务托管、QQ 组件与发行包还未验收，下面是源码验证方式，不是最终的一键部署流程。

## 准备与启动

安装项目声明的 Node 运行环境，建议使用与 Windows 内部包一致的固定 Node 24.22.1。项目目录中运行：

```sh
npm ci
npm run build
npm run web:build
```

选择独立可写的数据目录。Linux 示例：

```sh
npm run server:init -- --data-dir "$HOME/.local/share/WhaleWorkbench-server"
npm run server -- --data-dir "$HOME/.local/share/WhaleWorkbench-server"
```

Windows 源码验证可使用 `--data-dir 'D:\机器人独立测试数据'`。不要把真实凭据放进准备公开或提交的源码目录；初始化不会覆盖已有主人。命令行打印的一次性认领码只用于首次设置，15 分钟有效，不是 QQ 二维码、OneBot 令牌或模型密钥。

在服务器本机访问 `http://127.0.0.1:18380`；远程使用 SSH 隧道：

```sh
ssh -N -L 18380:127.0.0.1:18380 user@your-server
```

随后在自己的浏览器打开同一地址，用认领码设置至少 15 个字符的管理口令。关闭浏览器不等于停止管理服务。当前需要命令前台运行；系统服务托管将在 Linux 发行阶段补齐。

默认端口为 18380，可用 `--port` 修改；本地隧道与服务器端口不一致时，使用 `--origin http://127.0.0.1:本地端口` 明确浏览器访问地址。所有写请求要求精确匹配该来源，不能使用任意 Host/Origin。首轮不接受公网域名或公网监听设置。

## 认证、密钥与数据

- 一次性认领码和管理口令只保留哈希，口令采用随机盐的 scrypt；口令哈希计算限制并发，登录单独限速。
- 管理会话使用 HttpOnly、SameSite=Strict 的本机会话 Cookie，最长 12 小时，空闲 30 分钟失效；此回环 HTTP 模式不使用 Secure Cookie，也不能直接映射到公网。
- 浏览器内存只保留 CSRF 校验值，不在本地存储保存管理令牌。退出立即撤销对应会话和事件连接，重启服务后需重新登录。
- 配置接口只返回允许字段。密钥只显示是否已配置，URL 内的用户信息和敏感参数同样隐藏；原始 `.env`、未知自定义环境变量、聊天与模型输出不通过只读事件接口返回。
- 普通管理请求限 64 KiB；SSE 每会话最多两条连接，慢连接缓冲有上限，历史事件最多 256 条/128 KiB。页面隐藏时停止订阅，返回后重新获取状态。
- 状态只描述本管理核心持有的受管进程，不自动接管其它独立运行的桥接。进程运行、QQ 在线和模型协议连接分开显示，实际聊天能力须另行验证。

## 配置与任务

连接页先显示模型与 OneBot，更多服务、容量和只读路径放在折叠区域。只允许修改明确列出的模式、模型、地址、机器人账号及容量参数；不能通过网页改可执行文件、工作区路径、主人权限或自动命令执行。地址不能携带账号密码或敏感查询参数；旧地址中已有隐藏内容时须在本机修改，避免将脱敏文本误存回去。

配置修订号覆盖完整原文，使用服务实例私有 HMAC，不暴露原文摘要。保存前取得共享配置文件锁，检查预期修订号并原子替换，保留未知配置。其它页面或本机更改后返回 409，页面保留草稿；点击「重新读取配置」后继续保留输入，核对后再保存。重启管理服务会更换修订号，需要重新读取。手工编辑配置时应先停止管理服务；直接修改文件的编辑器不参与应用文件锁。

密钥使用独立入口，省略表示保留，替换要求非空值，清除需要明确选择及确认；成功后页面清空输入，响应只返回是否配置。清除当前模式必需的密钥也允许，但对应连接会缺少凭据。保存不触发隐式重启，按页面提示停止后重新启动。

启停和组件准备返回 202 与任务编号，重复操作编号返回原任务。任务执行前重新认证，只保留允许的阶段及通用结果，不保存请求密钥或底层错误。普通任务同时一个；组件准备期间可以独立取消，停止请求会先取消组件再排队停止。安装期间不接受配置保存。

任务历史最多 64 条、完成记录最长保留一天，仅在本次管理服务内存中保存。刷新浏览器可恢复状态，不自动重新提交；管理服务重启会清空历史和幂等记录，此时先检查实际进程与组件状态，再决定是否重新操作。任务带递增版本，较晚收到的旧 HTTP 响应不会覆盖较新的事件状态。

Windows 组件准备仍需在本机工作台核对并保存受管路径，不自动替换自定义路径。Linux 组件暂未提供，页面不显示准备按钮。该阶段未开放模型/QQ 任意地址测试代理，也没有通用命令接口。

当前主要接口为 `/api/config`（GET/PATCH）、`/api/secrets/:name`（PUT）、`/api/runtime/start|stop|restartBridge`（POST）、`/api/components/:id/prepare`（POST）、`/api/jobs` 与 `/api/jobs/:id`（GET）、`/api/jobs/:id/cancel`（POST）。所有写操作要求主人会话、精确 Origin 和 CSRF；请求结构拒绝额外字段。

本机恢复管理凭据：

```sh
npm run server:reset-auth -- --data-dir "$HOME/.local/share/WhaleWorkbench-server"
```

该命令撤销旧凭据并生成新的认领码；旧会话在后续认证检查时失效，已开的事件连接在下一次会话检查时关闭，最长约 10 秒。重新认领不会删除机器人聊天数据。凭据文件本身损坏时当前拒绝覆盖，保留文件供后续恢复工具处理。

`data/management/auth.json` 应与整个数据目录一起保护；不应分享初始化输出、会话 Cookie 或实际备份。首次正式云端发布仍需完成完整工具权限、进程树回收、备份恢复和 Linux 真实运行验收。

## 开发验证

```sh
npm run test:isolated
npm run test:web-ui
```

浏览器检查使用已有 Edge/Chrome，或通过 `WEB_SMOKE_BROWSER` 指定 Chromium 可执行文件，不自动安装浏览器。自动测试只使用临时主人、假密钥和假数据，不启动真实 QQ 或调用模型；截图在忽略的 `release/web-smoke-*` 中。

会话边界参照 [OWASP 会话管理建议](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)，密码派生使用 [Node scrypt API](https://nodejs.org/docs/latest-v24.x/api/crypto.html#cryptoscryptpassword-salt-keylen-options-callback)。认证与访问控制由项目明确实现，不能把选用框架等同于已经完成安全审计。
